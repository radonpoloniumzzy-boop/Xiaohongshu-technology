# 公开导出范围

目标库在本次核验为公开。用户明确要求上传账号与项目情况；本次仅导出所需汇总、作品数据、现有分析与状态索引。

排除项：登录Cookie/Token/授权头/浏览器profile、带访问参数的内部媒体URL、原网络响应与DOM、活跃粉丝昵称/名单、私人角色母本/课程库、原MP3/MP4/图片/剪映工程、整机配置与本地用户名。原包保留本机，需要时由所有者按范围提供。

账号名称与作品指标是本次被请求分享的账号资料；未添加收费服务账号身份或其他私人项目正文。素材来源、公开可访问与商业重剪许可是三件事，本库不把未知授权升级为可用。

验证脚本能发现部分常见秘密/绝对用户路径和缺文件，但不是对全部历史资料的安全保证；继续更新仍需显式字段选择与人工复核。
